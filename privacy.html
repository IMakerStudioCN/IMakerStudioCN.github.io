《浮言杂浪》VerbalDeluge

隐私政策

本游戏是由爱美客工作室开发的离线单机游戏。我们在本政策中明确承诺：不收集、不存储、不上传任何个人信息，未接入任何第三方 SDK。

目录 适用范围 不收集的信息 本地数据 第三方 SDK 网络与权限 平台方数据 未成年人 你的权利 政策更新 联系我们

适用范围

本政策适用于 Windows 桌面版游戏《浮言杂浪》（英文名 VerbalDeluge，可执行文件 VerbalDeluge.exe），包括其后续更新版本。

本政策仅说明本游戏自身的数据处理行为，不适用于你下载或运行本游戏所依赖的游戏平台客户端。

我们不收集的信息

本游戏没有账号系统，也不含联网功能。我们在任何情况下都不会收集、留存或传输下列信息：

  • 身份信息：姓名、昵称、头像、手机号码、电子邮箱、身份证件号码。
  • 账号与登录：游戏账号、密码，以及 TapTap、微信、QQ 等第三方账号的登录凭据与授权信息。
  • 设备标识符：IMEI、IDFA、OAID、MAC 地址、设备序列号、Android ID、SIM 卡信息。
  • 设备与系统信息：设备型号、操作系统版本、CPU 与显卡型号、屏幕参数、语言与时区。
  • 网络与位置：IP 地址、GPS 定位、Wi-Fi 或基站定位、粗略地理位置。
  • 使用行为：游戏进度上报、关卡与留存统计、点击行为、广告标识符与转化数据。
  • 日志与故障数据：崩溃日志、异常堆栈、性能与帧率数据。
  • 敏感权限数据：通讯录、短信、通话记录、相册与照片、麦克风、摄像头、剪贴板、已安装应用列表，以及存储介质内的其他文件。
  • 支付信息：银行卡号、支付账号、交易流水与账单。

本游戏不含内购、不含广告、不含联网社交，因此也不存在围绕付费与广告的定向分析。

本地数据说明

为了让游戏记住你的进度和设置，游戏会在你自己的设备上保存少量本地数据（例如存档、音量与显示设置）。这类数据：

  • 只写入本机，使用操作系统提供的本地存储机制，不经过任何服务器；
  • 不包含上述任何个人信息，无法用于识别你的真实身份；
  • 我们无法远程访问、读取或恢复。

你可以随时清除这些数据：在游戏内重置进度，或直接删除游戏安装目录，本地存档即随之删除。卸载游戏后，本地数据一并移除。

第三方 SDK

本游戏未接入任何第三方 SDK。下表按常见类别逐项说明，均为“未接入、无信息、无用途”：

统计与埋点

未接入。无友盟、神策、Google Analytics、Firebase 等，不采集任何使用行为。

广告与变现

未接入。无广告 SDK，不采集广告标识符，不做广告定向投放。

登录与社交

未接入。无 TapTap、微信、QQ 等第三方账号登录与社交分享。

支付与内购

未接入。无内购与虚拟货币，不处理任何支付信息。

推送与短信

未接入。不申请通知权限，不主动下发任何通知或短信。

崩溃与性能上报

未接入。无 Bugly、Sentry 等，崩溃信息不会上传至任何服务器。

本游戏使用 Unity 引擎构建，但未启用 Unity Analytics、Unity Ads、Unity Crash Reporting 等任何 Unity 官方联网服务，发布包内不包含联网统计组件。游戏目录中的 UnityCrashHandler64.exe 是 Unity 自带的本地崩溃处理器，仅在崩溃时于本机生成转储文件，不会上传。

网络与系统权限

本游戏运行不需要联网，断开网络后功能完全正常。游戏不申请任何敏感系统权限：不读取通讯录、短信、相册、麦克风与摄像头，不访问剪贴板，不扫描已安装应用列表。

游戏与系统之间的交互仅限于：读取自身安装目录内的资源文件，以及在本机保存存档与设置。

平台方独立处理的数据

当你通过 TapTap、Steam 或其他分发平台下载、启动或更新本游戏时，平台客户端或网页会按其自身的隐私政策处理你的账号信息、设备信息与日志信息。这些数据由平台方直接收集和控制，我们不会获得，也不受本政策约束。

如需了解平台方的处理规则，请查阅对应平台公布的隐私政策。

未成年人保护

本游戏不含联网功能、内购与社交互动。由于我们不收集任何个人信息，因此不存在针对未成年人的个人信息处理行为。

若监护人发现平台侧存在与本游戏相关的问题，可通过本页下方联系方式与我们沟通。

你的权利

《中华人民共和国个人信息保护法》等法规赋予你查阅、复制、更正、删除个人信息的权利。由于我们不持有你的任何个人信息，不存在可供查询或删除的远端数据；本地存档由你完全掌控，可随时自行删除。

若你对本政策或游戏的数据处理仍有疑问，欢迎联系我们。

政策更新

本政策的更新版本会发布在本页面，并同步修改文末的生效日期。若未来游戏新增任何数据收集功能（例如接入统计、账号登录或崩溃上报），我们会在版本发布前更新本政策并显著提示。
