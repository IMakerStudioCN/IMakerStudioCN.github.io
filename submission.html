两个通道，一套审核流程

投稿与维护

访客通过飞书推荐资源，无需登录 GitHub；管理者通过在线编辑器直接维护仓库内容。

01

面向所有访客

飞书投稿

填写名称、链接、分类、类型和说明。投稿先进入待审核列表，不会立即出现在网站。

  • 不需要 GitHub 账号
  • 公开表单可直接填写
  • 审核通过后自动生成草稿 PR
打开飞书投稿表单 ↗
02

仅限管理者

在线维护

使用 GitHub 登录 Pages CMS，在表单界面新增、修改或删除资源，保存后直接写入仓库。

  • 需要仓库写入权限
  • 适合日常内容维护
  • 保存后由 Pages 自动部署
进入管理者编辑器 ↗

访客投稿流程

审核之后，才进入网站。

  1. 提交访客填写飞书表单。
  2. 审核管理者检查链接并将状态设为“已通过”。
  3. 转入 GitActions 创建草稿 Pull Request。
  4. 发布管理者合并 PR，Pages 自动更新。
