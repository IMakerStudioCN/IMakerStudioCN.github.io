IRONCLAD / 07 - realistic modern tank study

Files:
  Ironclad_07.blend - editable Blender 4.5 scene
  tank_hero.png - studio render
  build_tank.py - reproducible procedural modelling script

Original fictional exterior design, inspired by modern main battle tanks.
Units are metres. Components are organised into named collections.
Materials are procedural and require no external texture files.
The turret and barrel have named parent controls for posing.
