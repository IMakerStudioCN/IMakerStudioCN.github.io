管理发布流程

审核、提交、验证。

  1. 审核核对链接、说明、分类、类型和标签。
  2. 同步运行 Actions，生成待审核的代码变更。
  3. 复核检查草稿 PR 中的资源数据。
  4. 发布合并 PR，等待 GitHub Pages 更新。
